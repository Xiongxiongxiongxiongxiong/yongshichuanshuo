## 已实现规则

每只拥有32帧：待机、移动、近击、大招、机动、特殊技、喘息、死亡各4帧。共享32帧特效；两套生成竞技场背景，石台有独立实体碰撞。血条放在上方，避免覆盖现有红骑士技能栏。

待机向玩家移动，距离约3.1停下，随机等待1.3–2.15秒后按距离加权选招。近击仅近距且玩家不在高处进入候选。沙漠两只和狱长距离至少6才考虑机动，沙蜥还要求玩家在主地面。机动不连续，同招最多连续两次。靠近不会强制后跳或钻地。

伤害按攻击编号记账：同一招的多颗弹体、二次落点和冲击波共享一次成功命中额度；持续区域不会反复扣血。攻击尊重无敌和滑铲。效果保留原攻击编号，避免下一招开始后刷新旧弹体伤害额度。

### 葬日沙蝎

- 巨钳近击：0.65秒前摇，15伤害，恢复0.8秒。
- 贯沙尾刺：锁定玩家所在表面，1.2秒预警，22伤害，区域2.4×1.6；半血后追加一个独立预警落点。
- 沙甲冲锋：1秒蓄力，沿地面移动，20伤害；撞障碍后喘息2秒。半血后未撞墙的冲锋有40%概率衔接0.65秒预警近击。
- 流沙陷区：主地面锁点，1.3秒前摇，持续3秒，仅减速至55%，不扣血。正常宽3.8、半血宽5；不在悬空石台上生成，也不影响台上的玩家。

### 负碑沙蜥

- 裂颚近击：0.7秒前摇，15伤害。
- 碎碑震地：1.4秒蓄力，前方24伤害，两侧低沙浪16伤害；半血后0.65秒间隔追加一组沙浪。沙浪碰实体地形销毁，台上可躲避。主要恢复窗口1.8秒。
- 埋沙突进：提前1.2秒锁定裂纹落点，浅沙中移动至固定位置后恢复碰撞，落点20伤害。半血后向两边甩出碎石；结束恢复2秒。
- 扇尾扬砂：1秒前摇，后方18伤害并扇形甩出碎石。

### 缚刑狱长

- 铁臂近击：0.7秒前摇，15伤害。
- 刑锤断地：1.3秒举锤，24伤害，嵌地恢复1.8秒；半血后向两侧产生16伤害低冲击波。
- 牢门冲撞：1秒蓄力，20伤害，撞墙恢复2秒；半血后未撞墙的冲锋有40%概率接预警近击。
- 锁链拖刑：1.1秒预警，低位掷锤16伤害，命中向狱长方向拉近最多2单位；投射物与拉动均检查地形，不穿柱、不穿石台。

### 无面司灯

- 幽爪近击：0.65秒前摇，15伤害。
- 囚魂巡游：1.2秒前摇，释放3发／半血5发直行魂火，12伤害，遇实体地形销毁，不持续追踪。
- 点名灯刑：1.4秒预警，前0.9秒跟随脚下表面，最后0.5秒锁定。爆发18伤害，2.4×2.6区域；高光圈体现高度，能标记石台。半血追加一个延迟光圈。
- 引魂归灯：左右边缘出现魂火及低回收路线提示，1.5秒后沿固定路线回收，16伤害。结束暗灯恢复2秒，始终可以攻击其身体。

半血阶段锁定于每招开始，使用暖色受怒提示和各自技能变体；当前没有另做整套二阶段外形图集。

## 接入与文件

- 运行逻辑：Assets/Script/Enemy/DesertDungeonBoss.cs、ArenaBossEffect.cs。
- 血条：Assets/Script/UI/DesertDungeonBossHud.cs。

- 数据：Game BossScene6.asset 至 Game BossScene9.asset；地址 BossScene_6 至 BossScene_9。
- persistent 的 additionalBossScenes 保存四份引用，使重新启动后的检查点可解析；原有五只BOSS字段保持兼容。
- 检查点为 Game BossScene6Entrance 至 Game BossScene9Entrance；出生点(-11,0.05,0)。
- 如需连接探索关卡，可把 BossLevelEntrance.destination 指向对应 GameSceneSO；本次没有擅自替换原探索路线。
- 素材与原图在本目录，均已复制到项目内；导入 Point/无压缩/无mipmap，Unity生成meta。160个独立Sprite资产包含128角色帧和32特效帧。
